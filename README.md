# CLUTCH — Elevá tu juego

Proyecto académico de Front-End para el Trabajo Práctico Intermedio. Es una maqueta de tienda online de periféricos gamer; los nombres, productos y precios son ilustrativos.

## Estructura
- `index.html`: página principal con navegación, hero, categorías, productos, galería, formulario y footer.
- `css/styles.css`: estilos, variables de color, Flexbox, efectos y media queries responsive.
- `assets/img/clutch-hero.png`: imagen de portada local creada como referencia visual del diseño.

## Cómo abrirlo
1. Descargá y descomprimí el ZIP.
2. Abrí la carpeta `CLUTCH` desde Visual Studio Code.
3. Abrí `index.html` y tocá **Go Live** (Live Server), o abrilo directamente en el navegador.

## Requisitos del TP contemplados
- HTML semántico: `header`, `nav`, `main`, `section`, `article`, `figure`, `form` y `footer`.
- Hero con imagen amplia, título principal único y botones de llamada a la acción.
- Cuatro tarjetas de categorías y cuatro tarjetas de productos con imagen, título, descripción, precio y acción.
- Galería de ocho imágenes, implementada con Flexbox y `flex-wrap`.
- Formulario con nombre (text), email, teléfono, select con más de tres opciones, radio, checkbox, textarea, botón enviar y botón limpiar.
- Google Fonts e iconos de Font Awesome.
- Diseño responsive con media queries para tablet y celular.
- Comentarios en el HTML y CSS para explicar la organización.

## Antes de entregar
- Las imágenes de productos y galería, las fuentes y los iconos externos requieren conexión a internet. La imagen principal está guardada localmente.
- El formulario es demostrativo: valida los campos en el navegador, pero no envía mensajes a una tienda real.
- Los precios son ficticios y se incluyen solo para la presentación académica.
- Subí el contenido a un repositorio público de GitHub y activá GitHub Pages desde **Settings → Pages**. Después entregá el enlace al repositorio y el enlace publicado.
